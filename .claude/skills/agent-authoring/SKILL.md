# agent-authoring

**Purpose:** Keep the team consistent as it grows.

**Used by:** Orchestrator, Meta Agent

**Inputs:** A role or skill to add or change.

## Steps

1. Follow the templates in the meta-agent file.
2. Every agent keeps the data-handling rules and How to answer sections.
3. Update docs/expert-roster.md and CLAUDE.md to match.

## Output

New or updated files.

## Rules

- Synthetic or user-written example data only; never real PHIRE ticket content (`docs/data-handling.md`).
