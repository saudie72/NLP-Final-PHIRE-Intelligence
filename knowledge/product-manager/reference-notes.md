# Product Manager reference notes

## Assignment requirements (NLP Final Exam guide)
- One app live on Netlify that works when opened.
- NLTK used in a clearly labelled part of the app; spaCy used in a clearly labelled part of the app.
- Repo has `docs/` research, `.claude/agents` (including an NLTK expert and a spaCy expert), `.claude/skills`,
  and a `knowledge/` folder for each agent with real notes and sources.
- App has a Resources page with every link the project relies on (official docs, GitHub repo, the guide).
- Grading: live app 25, NLTK 20, spaCy 20, agent team 15, knowledge 10, research and repo 10.
- Source: https://claude.ai/artifact/K55JqCeSxXULMmzki6yv73

## Writing requirements
- User story: "As a <role>, I want <capability>, so that <benefit>", with acceptance criteria.
- Acceptance criteria in Given / When / Then form make tests easy to write.
- Sources: https://www.atlassian.com/agile/project-management/user-stories, https://martinfowler.com/bliki/GivenWhenThen.html
