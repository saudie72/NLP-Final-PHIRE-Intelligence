# Knowledge: ux-designer (Noor)

Documents the **ux-designer** agent reads before every answer, in addition to `docs/`.

## What belongs here

- Usability and accessibility reference notes with official source links
- Approved wireframe and flow conventions for the app
- Past usability findings (synthetic data only) and how they were resolved

Markdown, plain text or PDF are best. Name files so their purpose is clear (for example `reference-notes.md`).

## Rules

- Only **synthetic** or **public** material. Never real PHIRE tickets, employee or user names, IDs, or ticket/CR numbers.
- No screenshots of real tickets; use screens built from `data/synthetic/`.
- Spreadsheets are blocked by `.gitignore` here; convert lists to Markdown tables (headers and value lists only).
- Every note cites its source. Remove anything outdated; the agent treats everything here as current.
