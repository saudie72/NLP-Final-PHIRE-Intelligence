# Knowledge: erp-business-analyst (Priya)

Documents the **erp-business-analyst** agent reads before every answer, in addition to `docs/`.

## What belongs here

- Business process maps (hire-to-pay, time-to-pay, procure-to-pay)
- Department org chart by role (no names)
- Cost assumptions (hourly rates, ticket handling time)
- Approved business cases

Markdown, plain text or PDF are best. Name files so their purpose is clear (for example `pay-calendar-2026.md`).

## Rules

- Only **synthetic** or **public** material. Never real PHIRE tickets, employee or user names, IDs, or ticket/CR numbers.
- Spreadsheets are blocked by `.gitignore` here; convert lists to Markdown tables (headers and value lists only).
- Remove anything outdated; the agent treats everything here as current.
